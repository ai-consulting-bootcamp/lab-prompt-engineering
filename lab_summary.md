In this lab, I tested three customer-service tasks—sentiment analysis, product description generation, and data extraction—using basic prompts (V1), clearer instructions and constraints (V2), and more structured prompts with examples or step-by-step extraction (V3). I ran repeated tests and compared format compliance, response length, and extracted information. The initial product prompt sometimes invented technical specifications. Sentiment and product-description checks improved from 0% in V1 to 100% in V2 and V3, although these checks did not measure full factual accuracy. Data extraction reached 100% valid JSON in V2 but dropped to 66.7% in V3 because some outputs included Markdown code fences; the model also invented a year that was not provided. After refining the formatting and date instructions, the final version produced valid JSON and passed the defined data checks in all 15 runs. I learned that more complex prompts are not always better. Next time, I would test more varied customer inputs, check factual accuracy separately from formatting, and use structured-output validation.
