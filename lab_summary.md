This lab evaluated zero-shot, constrained, few-shot, and structured-reasoning prompts for sentiment classification, product description generation, and customer-feedback data extraction. The initial prompts produced inconsistent formats, unsupported product claims, and non-standardized extraction results, while clearer instructions, explicit constraints, and defined output formats in V2 achieved 100% compliance across all three tasks. V3 few-shot and reasoning techniques maintained 100% compliance for sentiment and data extraction, and achieved 86.7% strict JSON compliance for product descriptions because two responses included Markdown code fences; variation tests still produced accurate results across all three tasks. The strongest lesson was that precise output requirements were more effective than simply making prompts longer, and next time I would test more ambiguous and diverse inputs and use stricter structured-output validation.
